# Quiz generation runs as a Strands agent on Bedrock AgentCore

Quizzes are generated by an agent written in TypeScript with the Strands Agents SDK, hosted on Amazon Bedrock AgentCore and calling Claude through Bedrock. This is more machinery than one structured-output call needs, and that is deliberate: the agent generates Questions, then verifies each one has exactly one defensibly correct Option, dropping or regenerating failures. It also avoids repeating Questions from the Host's existing Quizzes on similar Topics. Wrong answers are the biggest threat to a live Game, and the agent runtime leaves room to add tools such as web fact-checking later. It also keeps everything inside AWS (IAM auth, no API keys, one bill) and is a learning goal of the project.

## Consequences

- The model is Claude Opus 5.5 for both generation and verification. On Bedrock it is inference-profile only, so from ap-southeast-2 the agent calls the Australia geographic profile `au.anthropic.claude-opus-5-5`, which routes between Sydney and Melbourne. Quiz content carries no personal data, so the global profile is an acceptable fallback if the Australian one is ever throttled.
- **Temporarily superseded on the model choice (2026-10-26):** the dev account has no Anthropic model access yet, so the agent runs on Amazon Nova 2 Lite through the global profile. Models are now chosen by configuration and called only through the Converse API (ADR 0005). Opus 5.5 remains the intended model.
- Generation is slow (tens of seconds), so it is an asynchronous step that produces a Draft Quiz, separate from starting a Game.
